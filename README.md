### About me

I am a second-year engineering student in Computer Science at the Moroccan School of Engineering (EMG Rabat), after a bachelor's degree in Electronics, Automation and Computer Science at the Faculty of Sciences of Rabat (Mohammed V University).

I like work that sits between software and hardware: getting models to run where resources are limited, and building the tests and pipelines that make code reliable. Recently that meant compressing an object detector for drone inspection; before that, a RAG chatbot and a DevOps pipeline.

**Currently looking for a final-year internship (PFE)** in embedded AI, computer vision, or software/AI engineering. Feel free to write to me.

### What I'm working on

| | |
|---|---|
| **Edge AI / TinyML internship** | A Python framework that compresses a Faster R-CNN detector (structured pruning, knowledge distillation, INT8 quantization) for UAV power-line inspection. Includes a controlled comparison of pruning strategies, an error analysis per class, a second study on ResNet-18, and a deployment plan for a Raspberry Pi. Code and report are confidential, so numbers are not shown here. |
